# Catálogo de IDs · ACNL Welcome amiibo

Buscador de los códigos hex de 4 dígitos (IDs de objeto) de **Animal Crossing: New Leaf – Welcome amiibo (v1.5)**, para usar en editores de guardado y en Text to Item.

- 6.163 objetos, con buscador en español o inglés, o por código (por ejemplo `2096`).
- Imágenes y nombres oficiales del juego en español.
- Pensada para el celular: se adapta sola a la pantalla y se puede agregar a la pantalla de inicio como app.
- "Mi lista" para juntar varios códigos y copiarlos de una vez.

Es una página estática: `index.html`, más las hojas de imágenes en `s/` (16×16 miniaturas de 96 px por hoja).

## Fuentes
